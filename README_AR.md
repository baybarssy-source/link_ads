# استوديو إعلانات فيسبوك ← Google Play

صفحة وسيطة مجانية ودائمة على GitHub Pages: إعلان فيسبوك ← الصفحة (صورة الإعلان نفسها + المزايا + زرّ)
← تفتح تطبيق Google Play مباشرة بعد ثانيتين على أندرويد. بلا SDK ولا سيرفر ولا اشتراك.

## التشغيل
- أوّل مرّة: `تثبيت_المكتبات.bat`
- كل مرّة: `استوديو الإعلانات.bat`

## الإعداد مرّة واحدة (زرّ «إعداد الاستضافة» يشرحها خطوة خطوة)
1. «فتح أداة الالتزام» ← «أنشئ مستودعًا على GitHub» واجعله **عامًّا** (اسم قصير مثل `get`).
2. «قراءة المستودع» في استوديو الإعلانات، فيُملأ الرابط وحده.
3. «تفعيل GitHub Pages»: Branch `main` والمجلّد `/docs` ثم Save.

## إعلان لتطبيق جديد
«تطبيق جديد» ← الاسم ورابط المتجر والمفتاح ← الأيقونة وصورة الإعلان ← نصوص الإعلان
← «نشر على الإنترنت» (تفتح أداة الالتزام: «التزم وارفع») ← بعد دقيقة «تحقّق من النشر» ← «نسخ الرابط».
في مدير إعلانات ميتا: الهدف **الزيارات (Traffic)**، والوجهة **موقع ويب**، والصق الرابط، وارفع صورة الإعلان نفسها.

«تجهيز مقاسات فيسبوك» يصنع من صورة الإعلان مربّعًا وطوليًّا وقصصًا وعرضيًّا بلا قصّ، في مجلّد `صور الإعلان/<المفتاح>`.

**Meta Pixel (اختياري):** ضع معرّفه في «إعداد الاستضافة». الصفحة ترسل PageView عند الفتح وLead عند الذهاب إلى المتجر.

## الحفظ والنشر
كل تعديل يُحفظ وحده بعد لحظة، ولا زرّ حفظ. المؤشّر أعلى النافذة يقول «محفوظ · منشور» أو «محفوظ · لم يُنشر بعد»؛ والثانية تعني أنّ الناس يرون النسخة القديمة حتى تضغط «نشر على الإنترنت» ثم «التزم وارفع».

## نتائج الحملات
«إعداد الإحصاءات» مرّة واحدة: ملف مفتاح حساب الخدمة (نفسه الذي في ve_up)، ورابط مخزن التقارير من Play Console ← تنزيل التقارير ← «نسخ URI لـ Cloud Storage»، وإذن «تنزيل التقارير المجمّعة» لحساب الخدمة. ثم «تحديث الإحصاءات» متى شئت: جدول لكل تطبيق بالزوّار والتنزيلات ونسبة التحويل لكل حملة. قراءة فقط، والمسار والنتائج تبقى على جهازك.

## رابط واحد أم روابط؟
الموقع واحد لكل تطبيقاتك، ولكل تطبيق مفتاح (`?app=`). لا تُعِد استعمال مفتاح تطبيق لآخر: أنشئ تطبيقًا جديدًا. ولحملة جديدة للتطبيق نفسه غيّر «اسم الحملة» فقط.
